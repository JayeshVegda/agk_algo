# Playbook — Finish a task
- [ ] `pnpm typecheck && pnpm lint && pnpm test` pass
- [ ] `pnpm test:e2e` passes if a user flow changed
- [ ] Authorization covered by a test (user vs admin vs anonymous)
- [ ] Migration included if the schema changed; seed updated if needed
- [ ] No secrets in code, logs, or responses
- [ ] Strings are in the central strings file (for future translation)
- [ ] Docs updated if behaviour or schema changed
- [ ] Plan task ticked and a line added to its Progress Log
- [ ] Commit message states what and why
