AKG ALGO MetaTrader robot installation and activation
===================================================

Before you start
----------------
- Check the robot's product page for the supported MetaTrader version,
  instruments, timeframes, and any account requirements.
- Sign in to https://akgalgo.com/account after your payment is approved.
  Download the robot file and copy your license key from My Account.
- MT4 uses .ex4 files. MT5 uses .ex5 files.

Install the robot
-----------------
1. In MetaTrader, select File > Open Data Folder.
2. Open MQL4/Experts for MT4 or MQL5/Experts for MT5.
3. Copy the downloaded file into the Experts folder.
4. In Navigator, refresh Expert Advisors, or restart MetaTrader.
5. Attach the robot to a chart supported by the product. Enter your license
   key if prompted and follow the product-specific activation instructions.
   Use the MetaTrader account you intend to license.

Troubleshooting
---------------
- Robot missing from Navigator: check the folder and whether the file matches
  your MetaTrader version.
- License rejected: verify the key, the connected MetaTrader account, and any
  WebRequest instructions supplied with the product. The license can bind to
  a MetaTrader account on activation.
- For help, use the support contact listed at https://akgalgo.com/. Include
  the robot name and the error message. Keep passwords and license keys private.

Trading can cause financial loss. Read https://akgalgo.com/risk before use.
